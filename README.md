# Data Analyst Portfolio

## Project 1: Promotions & Price Elasticity Analysis

### Project Overview
Analyzed pricing, promotions, and revenue trends using SQL, regression analysis, and Power BI.

### Tools Used
- EXCEL
- MySQL
- Power BI
- Regression Analysis

### Work Performed
- Performed data cleaning and validation.
- Designed a relational schema in SQL.
- Developed analytical SQL queries.
- Conducted regression analysis.
- Identified key performance indicators (KPIs).
- Created a Power BI dashboard to analyze revenue trends.
